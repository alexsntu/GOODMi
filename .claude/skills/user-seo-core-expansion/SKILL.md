Прочитай файл `.cursor/skills/seo-core-expansion/SKILL.md` целиком и выполни описанный в нём workflow строго по шагам для категории, переданной вместе с этой командой.

Используй MCP-инструменты `mcp__wordstat-mcp__*` (broad + quoted частота, гео-каскад Севастополь/Симферополь/Крым) и `mcp__pixelplus-mcp__pixelplus_get_queries` (project_id=63589, весь проект без group_id) для сверки на дубли. Ничего не пиши в PixelPlus и не создавай страниц — результат только файл в `Расширение семантики/`.
