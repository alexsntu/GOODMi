## Рекомендации

### Немедленно
Ничего критичного не требуется — доступ уже открыт.

### В этом месяце
1. **Добавить `llms.txt`** — единственный минус в скоринге (`geo-llmstxt` уже установлен, можно сгенерировать через него).
2. **Опционально: явный `User-agent`-блок для Bytespider** — сейчас он тоже наследует `Allow: /` через wildcard. Скилл рекомендует блокировать его для западного рынка (агрессивный краулинг, Крым — не целевой рынок ByteDance), но это не критично, эффекта на GEO-видимость не даёт.

```
User-agent: Bytespider
Disallow: /
```

### Дополнительные технические находки
- **Meta Robots Tags:** на главной странице — `<meta name="robots" content="index, follow">`, не блокирует.
- **X-Robots-Tag заголовки:** отсутствуют на всех 3 проверенных страницах (главная, `/smartfonyi/`, `/blog-xiaomi-na-russkom/`) — не блокирует.
- **JavaScript-рендеринг:** сайт полностью server-side rendered (CS-Cart/PHP) — H1, title, навигация (585 ссылок), 4 JSON-LD блока присутствуют в сыром HTML без выполнения JS. Это важно: GPTBot/ClaudeBot/PerplexityBot не выполняют JS, а на goodmi.ru им и не нужно.
- **`llms.txt`:** отсутствует (404).
- **`/ai.txt`:** отсутствует (404) — не проблема, это неутверждённый черновой стандарт, не обязателен.
- **`/.well-known/ai-plugin.json`:** отсутствует (404) — устаревший формат плагинов ChatGPT, больше не используется OpenAI, не нужен.
- **Sitemap:** `https://goodmi.ru/map/sitemap.xml` и `https://goodmi.ru/posts1.xml` — оба отдают 200, не заблокированы в robots.txt.
