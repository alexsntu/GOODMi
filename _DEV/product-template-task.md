## Технический план

### Путь к файлу шаблона
```
/design/themes/abt__unitheme/templates/addons/my_changes/blocks/product_templates/
  goodmi_product.tpl           ← основной шаблон (СОЗДАТЬ)
```

### Как CS-Cart подхватит шаблон
- Все `.tpl` файлы из `product_templates/` автоматически появляются в выпадающем списке
- Выбор шаблона: Администрирование → Настройки → Внешний вид → «Отображение страницы товара»
- Или: Товары → Категории → вкладка «Внешний вид» → поле шаблона
- Или: Товары → конкретный товар → вкладка «Общее» → поле шаблона

### Основные Smarty-переменные
- `$product.product_id` — ID товара
- `$product.product` — название
- `$product.price` / `$product.list_price` — цена / старая цена
- `$product.main_pair` — главное изображение
- `$product.image_pairs` — вся галерея
- `$product.options` — опции (цвет, память…)
- `$product.product_features` — характеристики
- `$product.in_stock` — наличие
- `$product.short_description` — краткое описание
- `$product.full_description` — полное описание
- `$product.tabs` — вкладки (описание, отзывы…)

## Макет (DNS-стиль)

**Десктоп (2 колонки):**
- Левая (46%): краткие хар-ки → рейтинг → цена → кредит → купить → USP → опции → бренд+SKU
- Правая (54%): галерея (sticky)

**Полная ширина:** хлебные крошки + H1 + SKU (вверху) | вкладки (внизу, без изменений)

**Мобайл:** стандартный UniTheme2 `abt__ut2_mobile_template.tpl` (пока без изменений)

## Ключевые технические решения

- **Кредит:** 75% годовых, аннуитет, 12 мес. → JS рассчитывает из `data-price` атрибута
- **Галерея:** справа, sticky; thumbnail position — из настроек темы (`images-{setting}`)
- **Краткие хар-ки:** только если `show_features === YES` и `$product.header_features` не пусты
- **Наличие:** динамически `$product.in_stock` — серый/оранжевый USP-блок
- **SKU:** показывается вверху справа (`#product.product_code`) и в нижней строке бренда

## Следующий шаг

1. Загрузить `goodmi_pd.tpl` на сервер (путь выше)
2. Убедиться что аддон `my_changes` активен: Модули → Управление модулями → My Changes
3. Открыть любой товар → вкладка «Общее» → поле «Шаблон страницы товара» → выбрать `goodmi_pd`
4. Проверить отображение и прислать скриншот / список правок
