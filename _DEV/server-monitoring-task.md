# Задача: Мониторинг сервера (goodmi.ru, maxmobiles.ru, xione.ru)

**Сервер:** VPS под управлением ISPmanager, Debian 11
**Стек:** Apache MPM-ITK + nginx (PageSpeed) + PHP-FPM (5.6–8.3) + MariaDB 10.5 + phpMyAdmin + ProFTPD + Fail2ban + BIND + Exim/Dovecot
**Docker:** не установлен · **Python:** установлен · **Node.js:** не установлен
**Домены на сервере:** goodmi.ru, maxmobiles.ru, xione.ru (общий сервер, ресурсы делятся между всеми тремя)

**Способ выполнения:** у ассистента нет прямого SSH-доступа. Пользователь выполняет команды сам через SSH/консоль ISPmanager, шаг за шагом, присылает вывод — ассистент проверяет и даёт следующий шаг. Настройка ведётся постепенно, не за один присест — поэтому важно фиксировать прогресс здесь.

---

## Выбранное решение

| Компонент | Инструмент | Уровень | Зачем |
|---|---|---|---|
| Ресурсы сервера (CPU/RAM/диск/сеть) | **Netdata** | сервер целиком (общий для всех 3 доменов) | лёгкая установка без Docker, готовый дашборд, автообнаружение Apache/MariaDB/PHP-FPM |
| Доступность сайта | **UptimeRobot** | по домену — 3 отдельных монитора | внешняя проверка, сработает даже если сервер целиком недоступен |
| Ошибки PHP/CS-Cart (5xx) | Netdata, log-мониторинг | по vhost-логу каждого домена (донастройка) | чтобы не мешать ошибки всех трёх сайтов в одну кучу |
| Алерты | Telegram (решено ранее) | — | быстрее email, мгновенно на телефон |

## Подготовленные команды (для копирования на сервере)

### Шаг 2 — установка Netdata
```bash
wget -O /tmp/netdata-kickstart.sh https://get.netdata.cloud/kickstart.sh
sh /tmp/netdata-kickstart.sh --stable-channel --disable-telemetry
```
