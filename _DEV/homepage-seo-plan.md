## Приоритет 1 — Критические (технические ошибки)

### 1.1 Показать H1
- **Проблема:** `<h1 hidden="">Интернет-магазин оригинальной техники Xiaomi</h1>` — H1 скрыт атрибутом `hidden`
- **Что делать:** убрать `hidden`, визуально разместить H1 на странице (стилизовать под подзаголовок)
- **Файл:** правка в CS-Cart Layout → блок с H1
- **Статус:** [x] выполнено (было исправлено до начала сессии)

### 1.2 Убрать @graph из JSON-LD
- **Проблема:** схема на странице использует `@graph` — запрещено (CS-Cart несовместимо)
- **Что делать:** пересобрать Organization + ItemList без `@graph`, каждая схема отдельным `<script type="application/ld+json">`
- **Файл:** `HOMEPAGE-REVIEWS-SHORT-BLOCK-2026-03-24.html`
- **Статус:** [x] выполнено (2026-06-15)

### 1.3 Исправить OG:image
- **Проблема:** `og:image` = SVG-лого — не рендерится в ВКонтакте и Telegram
- **Что делать:** заменить на PNG/JPG через UniTheme2 template hook `meta.post.tpl` с проверкой `$runtime.company_id == 2`
- **Файл:** `design/themes/.../hooks/index/meta.post.tpl`
- **Статус:** [x] выполнено (2026-06-15) — использован Logo-Goodmi-n.png

### 1.4 Исправить sameAs в Organization
- **Проблема:** нет главного Яндекс.Карты URL; прописаны testimonials, vk, avito, otzovik
- **Что делать:** добавить `"https://yandex.ru/maps/org/goodmi/81345582117/"` в sameAs; убрать /testimonials/ (не внешняя площадка)
- **Файл:** `HOMEPAGE-REVIEWS-SHORT-BLOCK-2026-03-24.html`
- **Статус:** [x] выполнено (2026-06-15)
