### 5. SSH к серверам (свой ключ, закрытый ключ `a0000` не копировать)

```bash

ssh-keygen -t ed25519 -f ~/.ssh/price_maxmobiles_ed25519 -C "alex-max - price-maxmobiles SSH"
cat >> ~/.ssh/config <<'CFG'
Host goodmi
    HostName 176.123.171.223
    User root
    IdentityFile ~/.ssh/goodmi_ed25519
Host price-maxmobiles
    HostName 91.219.151.252
    User root
    IdentityFile ~/.ssh/price_maxmobiles_ed25519
CFG
cat ~/.ssh/goodmi_ed25519.pub ~/.ssh/price_maxmobiles_ed25519.pub
```

Две выведенные строки (открытые ключи) передать Claude в учётной записи `a0000` – он добавит их на серверы
(`/root/.ssh/authorized_keys`). При первом подключении сверить отпечаток ключа сервера goodmi:
`SHA256:DUoMw7OcPvfpezzmAYgd+tpzSB9TF2brKiifSXDlNig`.
Через VPN HAPP SSH не проходит – как и у `a0000`, нужен маршрут в обход (команду с `sudo` запускает пользователь):
`sudo route -n add -host 176.123.171.223 $(ipconfig getoption en0 router)`.

## Правила попеременной работы

1. **Не запускать Claude в обеих учётных записях одновременно** – общая память и рабочие файлы могут перезаписать друг друга.
2. **Перед сменой учётной записи – закоммитить** («закоммить всё») и сказать «запомни всё» – тогда во второй
   учётной записи Claude увидит и историю git, и заметки.
3. Новую сессию начинать с «с чего продолжаем?» – Claude прочитает раздел «С чего продолжить» в памяти.
4. Разрешения инструментов (`~/.claude/settings.json`) у каждой учётной записи свои – в `alex-max` Claude первое время
   будет чаще спрашивать подтверждение.
