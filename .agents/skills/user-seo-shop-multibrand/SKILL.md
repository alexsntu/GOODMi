Прочитай файл `.cursor/skills/seo-shop-page-builder-multibrand/SKILL.md` целиком (файл большой — если первое чтение обрежется, дочитай остаток через offset) и выполни описанный в нём workflow строго по шагам для запроса пользователя, переданного вместе с этой командой.

Обязательные блокирующие шаги — не пропускать:
- Step 1b: спросить гарантию, если не указана.
- Step 2a-multi: проверить каждый бренд страницы (включая Xiaomi, без исключений) по таблице «официальный магазин-блокер».
- Step 4: спросить URL картинок для карточек (или явное «пропустить»/«без фото») до вёрстки `.gm-services-grid`.

Не подставлять бренд по умолчанию нигде (FAQ, лид, advantages-list, JSON-LD) — состав брендов страницы берётся из ответа пользователя, не из архивной справки Xiaomi-эры в конце файла скилла.

Сгенерируй два файла (`[slug].html` и `[slug]-jsonld.html`) и сохрани их в `Категории/Новые/`.
