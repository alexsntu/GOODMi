# SEO Roadmap GOODMi (Q2 2026)

Рабочий план для `goodmi.ru`, по которому двигаемся итерациями.

## 1) Цели и KPI

### Бизнес-цель
- Увеличить долю коммерческого SEO-трафика в приоритетные категории и поднять продажи из органики.

### Ключевые KPI (база -> цель за 90 дней)
- Доля кликов на коммерческие URL: `20.2%` -> `30-35%`.
- Клики на приоритетные категории: `+35-50%`.
- Средний CTR по кластерам с позицией 4-10: `+0.8-1.5 п.п.`.
- Снижение "Crawled/Discovered - currently not indexed": `-25-40%`.
- Снижение 404/soft-404 в индексе: `-50%` (по массовым шаблонам).

## 2) Приоритетные направления

### Категории (по очереди запуска)
1. Смартфоны
2. Пылесосы
3. Телевизоры
4. Смарт-часы
5. Мониторы
6. Планшеты
7. Наушники
8. Грили
9. Внешние аккумуляторы
10. Ноутбуки

### Принцип приоритизации
- Сначала страницы с большим числом показов и позицией 4-12.
- Затем страницы с высоким спросом и слабым CTR.
- Далее расширение структуры под длинный хвост.

## 2.1) Фикс-стандарт мета-тегов (не меняем)

Эти правила обязательны для всех следующих итераций и не пересматриваются без отдельного решения.

### H1 (UX-first)
- H1 должен быть коротким и понятным пользователю.
- Для карточек товара: формат по умолчанию `Тип товара + Модель` (например, "Смартфон Redmi Note 14 Pro Plus", "Планшет Xiaomi Pad 7").
- Допускается только название модели, если тип товара уже явно считывается на первом экране и добавление типа ухудшает читаемость.
- В H1 карточек не использовать "Купить", гео и бренд магазина.
- Для категорий: короткое название категории/подкатегории.
- Запрещено делать H1 в формате SEO-фразы для выдачи, если это ухудшает читаемость.

### title (SEO-commercial)
- Основной коммерческий ключ и гео выносим в `title`.
- Формат: `[Запрос/модель] — цена, купить в Крыму | GOODMi` (или близкий).
- Держим длину в рабочем диапазоне сниппета, без переспама.

### meta description
- Описывает выгоды и условия покупки, но без недоступных офферов.
- Обязательные реальные УТП: гарантия, доставка, самовывоз, трейд-ин, кредит.
- Не использовать формулировку "рассрочка без переплат".

### Коммерческие условия (обязательно)
- Используем только корректную формулировку: "кредит".
- Любые варианты "рассрочки" в мета-тегах и SEO-блоках запрещены.

## 3) План работ на 30 / 60 / 90 дней

## Этап A: 0-30 дней (технический фундамент + быстрые победы)

### A1. Техническая стабилизация индексации
- Проверить и починить sitemap (все карты должны отдавать `200 OK`).
- Переотправить карты в Google Search Console и Яндекс Вебмастер.
- Разобрать Coverage-группы: 404, 5xx, blocked by robots, excluded by noindex.
- Убрать массовые 404: 301 на релевантные URL или 410 для мусорных адресов.
- Проверить robots.txt на слишком широкие маски и скорректировать.

**Результат этапа:** индексируемость и обход стабильны, устранены критические тех-барьеры.

### A2. Быстрый CTR-апгрейд
- Переписать title/description у топ-страниц с большими показами и CTR < 2%.
- Добавить в сниппеты коммерческие триггеры: "в наличии", "официальная гарантия", "доставка по Крыму".
- Приоритет: Смартфоны, Телевизоры, Смарт-часы, Планшеты.

**Результат этапа:** рост кликов без ожидания роста позиций.

### A3. Перелинковка "блог -> коммерция"
- Для 20-30 топ-статей добавить блок "Подобрать в каталоге GOODMi".
- Ссылки вести в соответствующие категории/подкатегории.
- Использовать релевантные анкоры под интент покупки.

**Результат этапа:** перераспределение информационного трафика в продажи.

## Этап B: 31-60 дней (усиление money pages)

### B1. Редизайн SEO-контента категорий
- Обновить тексты категорий под коммерческий интент (без переспама).
- Добавить FAQ-блоки под частотные вопросы.
- Добавить блок "чем отличаются серии/модели".
- Внедрить быстрые ссылки (faceted quick links) в категориях.

### B2. Структурные доработки
- Расширить подкатегории по фильтрам с частотным спросом.
- Убедиться в корректных canonical/noindex для фильтрованных страниц.
- Создать/усилить хабы брендов и серий внутри приоритетных категорий.

**Результат этапа:** рост релевантности и покрытия по коммерческим кластерам.

## Этап C: 61-90 дней (масштабирование и закрепление)

### C1. Контент-кластеры под продажу
- Для каждой приоритетной категории: 3-5 статей "выбор/сравнение/гайд" в месяц.
- Каждая статья обязана вести на 2-4 коммерческих страницы.
- Фокус на запросах с позицией 5-15 и высоким impressions.

### C2. Работа с PDF-трафиком
- Определить PDF, которые ранжируются вместо коммерческих URL.
- Для важных запросов сделать HTML-аналоги (карточка/категория/лендинг).
- Нецелевые PDF ограничивать для индексации.

### C3. Повторный тех-аудит
- Проверить динамику Coverage и Core Web Vitals.
- Закрыть оставшиеся техдолги по индексации и шаблонным ошибкам.

**Результат этапа:** устойчивый рост коммерческой органики и конверсий.

## 4) Backlog задач по каждой приоритетной категории

Для каждой категории делаем одинаковый набор:
- Семантическое ядро (коммерция + инфо-поддержка).
- Карта URL: категория, подкатегории, хабы, карточки-лидеры.
- Новые мета-теги (H1/title/description).
- SEO-блок на категории (FAQ + преимущества + quick links).
- Перелинковка из блога.
- Контроль индексации и CTR.

## 5) Роли и ритм работы

### Еженедельный цикл
- Пн: выбор задач спринта и целевых URL.
- Ср: внедрение правок.
- Пт: проверка KPI и корректировка приоритетов.

### Роли
- SEO-стратегия и приоритеты: владелец проекта.
- Внедрение HTML/мета/контента: контент+верстка.
- Техблок (sitemap, robots, redirect): разработка.

## 6) Дашборд контроля (обязательный)

Обновлять еженедельно:
- Клики / показы / CTR / позиция по 10 приоритетным категориям.
- Доля коммерческих кликов в общей органике.
- Кол-во URL в статусах Coverage (404, 5xx, Crawled not indexed, Blocked by robots).
- Кол-во страниц с обновленными мета-тегами и контентом.
- Кол-во добавленных внутренних ссылок из блога.

## 7) Что делаем сразу после утверждения плана

### Sprint 1 (первые 7 дней)
1. Починка sitemap и проверка индексации.
2. Список top-30 URL с высоким impressions и низким CTR.
3. Переписываем мета-теги для первых 10 URL.
4. Ставим внутренние ссылки из 10 самых посещаемых статей блога.
5. Формируем ТЗ на обновление 3 категорий: Смартфоны, Пылесосы, Телевизоры.
