# Project Instructions — GOODMi

## Generate Commit Message

- Писать сообщения коммитов **на русском языке**
- Кратко: 1–2 предложения
- Без английского текста в теле сообщения
- Пример: «Обновлён HTML акции отзывов за апрель 2026»

## Продолжение переработки категорий и меты

- Если пользователь говорит «продолжаем мету», «перезаливка категорий», «как вчера» или «далее» в контексте этой задачи, сначала прочитать `_DEV/category-rework-handoff.md`, затем `_DEV/positioning-rebrand-task.md` и сверить фактические папки категорий.
- Для меты пользователь явно выбрал **`.cursor/skills/seo-meta-builder-multibrand/SKILL.md`**. Читать и применять именно этот скилл; не заменять его упрощённым составлением тегов или legacy v1/v2. При недоступности Wordstat использовать только предусмотренный скиллом fallback и сообщать об ограничении.
- Обрабатывать одну категорию за раз: существующие HTML + JSON-LD, перенос из `Категории/Готовые/` в `Категории/Новые измененные/`. Публикует и переносит в `Категории/Перезалитые/` пользователь.
- После каждой категории обновлять точку продолжения и выдавать ссылки на оба файла, H1, Title, Description и WebPage.description отдельными блоками для копирования.
